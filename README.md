## Sobre o Projeto

Este projeto implementa o produto entre duas matrizes, **A** (de dimensão *m × n*) e **B** (de dimensão *n × p*), resultando em uma matriz **C** de dimensão *m × p*.

---
## ⚙️ Funcionamento

O programa realiza as seguintes etapas:

1. Declara as matrizes de entrada **A** e **B**;
2. Obtém as dimensões *m*, *n* e *p* a partir das próprias matrizes;
3. Calcula a matriz **C** por meio de três laços aninhados (linhas, colunas e somatório);
4. Exibe a matriz resultante no console.
